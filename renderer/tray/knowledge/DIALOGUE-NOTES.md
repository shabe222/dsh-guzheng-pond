# 对话档案·《秋》《冬》（2026-10-26）

> 规格只写“做什么”，这份档案写**为什么、不要什么、以及用户原话**。
> 用途：AI 写同题材的曲子时先读这份，别重新发明。

## 一、用户的原话（这是最精确的规格，不要翻译掉）

- 「快的时候可能 0.1 秒一个音符，然后用力一扫弦，安静一下，再渐渐铺垫」
- 「心里暗潮涌动，但就是不喷发出来，一直酝酿的那种感觉，就是装货的那种」
- 「间隔、技法、力度等等表现不灵活，没有很好配合调调，所以一段一段的」
- 「调调确实在走」
- 「大范围来看还是平静，主要是想凸显残酷」
- 「那个就是适合炫技的，技巧完全成熟，做很快节奏的音符跳跃……我们这种平静的氛围没有必要」
- 「一个音落下来，等它的音结束了，我们再继续弹」
- 「明明之前还是金木水，结果变了很多元素，感觉有点不太好」
- 「第二组的尾音和第一组一致……变掉的话就是中间的波形变一下」
- 「不是加偏音，是力度、间隔的问题」
- 「等前面一个音的余音刚好结束了那一刹那，扣下落」
- 「起绰是引，落音是扣」

## 二、为什么（规格背后的理由，AI 不知道理由就会乱用）

| 做法 | 理由 |
|---|---|
| 落音前留空 | 古筝的魅力在余音；余音没走完就弹下一句，显得“赶” |
| 尾音锁死 | 骨架不动、血肉换——听的人每句都知道要落在哪，不会迷路 |
| 元素渐入 | 耳朵认了一个“家”，突然换屋子就是换曲 |
| 残酷不用快音 | 残酷是冷、慢、不可逆；快是热血 |
| 同音连打要人化 | 完全一样的重复 = 电子鼓；时值/力度/音高三样至少动两样 |

## 三、不要什么（否定清单，比“要什么”更重要）

- ❌ 不要整首抬八度做高潮（那是“扬”，不是“残酷”）
- ❌ 不要在平静段用快音跳跃和连打（炫技段专属）
- ❌ 不要让新元素空降（必须 0→2→3 渐入）
- ❌ 不要把每句都落同一个音（同一落音连续 ≤2 句）
- ❌ 不要全曲只用主元素（必须留宫/商当连接音，否则级进上不去）
- ❌ 不要让 A' 换尾（尾音要锁死，只改身子）
- ❌ 不要用偏音来制造“挣扎”（力度和间隔就够了）

## 四、音程的味道（手感词典）

| 音程 | 味道 |
|---|---|
| 金→水（2→6，四度上） | 往上一挑，像风起来 |
| 水→金（6→2，四度下） | 往下一沉，像凉下来 |
| 金→木（2→3，级进） | 走一步，最自然的“说话” |
| 木↔水（3↔6，小三度） | 来回晃，叶子被风推 |
| 金金（2 2 同音） | 敲两下，像冷意到了两次 |
| 宫（1） | 回家的音；用多了就“每句都给答案” |
