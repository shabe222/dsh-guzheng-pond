# 和风·第二版：都节音阶，但要灵动

> 第一版的问题：音阶对了（只用 2/5/6 + 按音 F/C），但**24 句全是 6 个音**、没有刮奏、
> 按音都 0.12 秒就按死、摇指只有一个速度——所以"是日本味，但不够灵动"。

## 一、音阶（不变，只有这五个）

`2`（E）｜`2p100`（F）｜`5`（A）｜`6`（B）｜`6p100`（C）
**不许出现 1（D）和 3（F#）**。

## 二、句长必须分布（不许全 6）

24 句，按这个数量写：

| 每句音数 | 句数 |
|---|---|
| **4 音** | 4 句 |
| **5 音** | 5 句 |
| **6 音** | 7 句 |
| **7 音** | 5 句 |
| **8 音** | 3 句 |

气口也分三档：短句后 400–500、中句后 600–750、长句后 800–1000。

## 三、灵动的四件事（这一版的重点）

1. **刮奏（かき）**：2 处，用上扫 `5s:14:0.28` —— 轻、快、一下掠过，然后立刻收
2. **慢按（押し上げ）**：3–4 处用 `2p100s400`、`6p100s500` —— 按音要用 0.4–0.5 秒慢慢按上去，不要 0.12 秒按死
3. **摇指两个速度**：一处 `6Y60/2000`（急，紧张），一处 `6p100Y110/2200`（缓，颤着散）
4. **偶尔高八度**：5–8 个音写到高八度（`2.` `5.` `6.`），像筝的高音区亮一下

## 四、结构（24 句，2–2.5 分钟）

```
1-4   引：只有 2 和 6，慢，气口 900
5-14  起：加入 F 和 C，句长开始变化
15-18 转：刮奏 1 处 + 慢按 2 处 + 摇指 1 处
19-22 收：回到 2 和 6，一个高八度亮一下
23-24 尾：6p100 悬着不落
```

## 五、力度

大部分 `-`（44）；刮奏和摇指处 64/88；不要整段 88。

## 六、旋律三条底线（机器查，2026-10-26 加）

上一版的数据：级进只有 34–40%（真实中文旋律约 **64%**），96–100% 的句子和前面某句重合 ≥50%。
**跳得太多、抄得太多**——这是“不灵动”的另一半原因。

- **级进 ≥55%**：相邻两个音的音程 ≤2 半音才算级进。跳进（5→2、2→6）要少，
  想跳的时候先走两步再跳（`2 5` 改成 `2 6 5` 或者 `2 2p100 5`）
- **家族 ≤85%**：和前面某句重合 ≥50% 的句子不超过 85%（现在要接近 100% 就错了）
- **句长标准差 ≥1.2**：别句句一样长

自查（交卷前跑）：
```
node tray/lib/qin-tools.mjs check --melody -
```

## 六·补、落点三条（2026-10-26 加，实测发现的硬伤）

上一版的数据：**24 句里 22 句落在 2**（落点链 2→2×22），而且 71–75% 的落点是**跳进去**的。
所以听着是"一句句砸下来、每句同一个句号"。

- **落点要轮换**：只在 **2 / 5 / 6** 里轮（都节没有 1 和 3），**同一个落音不连续超过 2 句**
- **落点前一个音要级进走进去**（≤2 半音）：F→E、B→A、C→B；不要从 A 直接跳到 E
- **正好 24 句**

自查（三套一起跑）：
```
node tray/lib/qin-tools.mjs check --wa --melody --cadence -
```

## 七、自查

```
□ 有 5-8 个高八度的音吗？
□ 结尾悬着吗？
□ check --melody 过了吗（级进≥55%、家族≤85%、句长SD≥1.2）？
```
