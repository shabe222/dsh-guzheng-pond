# I1 五声旋律统计（现代研究，非古籍）

> ⚠️ 本格是**现代研究**：对 aiSong 数据集（2323 首 MIDI 编码歌曲）做旋律统计，非古籍原文。
> 数据：C:/tools/dsh-ambient-music/corpus/a虁iSong_dataset（每首 = KeyMode 行 + MIDI 音高序列行）。
> 统计方法：均匀采样 465 首（450 首含有效音符，共 42947 个音），2026-10-26 实跑。

## 实测结果（现代统计）

### ① 音级分布：大调五声（0,2,4,7,9）合计 62.4%
| 音级(pc) | 占比 |
|---|---|
| 0 (宫/主音) | 14.19% |
| 2 (商/大二度) | 11.59% |
| 4 (角/大三度) | 13.55% |
| 7 (徵/纯五度) | 11.63% |
| 9 (羽/大六度) | 11.43% |
| **五声小计** | **62.39%** |
| 1,3,6,8,10,11（半音/偏音）合计 | 28.17% |
| 5 (清角/fa) | 7.66% |

- **这对写曲意味着什么（现代视角）**：流行歌曲的主干音确实集中在大调五声上（62%），但**不是只用五声**——偏音合计 28%，清角 7.66%。这印证 C1「五正为本、二变可用」：现代旋律也是五声打底 + 偏音调味。给工具的启示：全曲 100% 五声（如 BRAIN「全曲只有 1 和 2」的极端）反而是异类，适度偏音（10-28%）才是现代听感的常态。

### ② 音程分布：同音反复占 77.7%，大二度 10.2%，小三度 3.9%
| 音程 | 占比 |
|---|---|
| 0（同音） | 77.74% |
| 2（大二度） | 10.17% |
| 3（小三度） | 3.94% |
| 1（小二度） | 2.54% |
| 5（纯四度） | 2.00% |
| 4（大三度） | 1.68% |

- **这对写曲意味着什么（现代视角）**：现代旋律**大量同音反复**（78%）——这与古琴审美（B1 洁况「取音从多到寡」）相反，但解释了「为什么流行歌重复多仍好听」：重复是主音归属感的来源。给工具的启示：古风/琴风曲应压低同音反复（<40%？），流行风可保留高重复；「呆」的判据不是重复本身，而是重复时没有变化（呼应 BRAIN「同音连弹三下要变长短轻重」）。

### ③ 与古籍的对照（本格结论，现代数据 vs 古籍观点）
- 现代五声旋律（62% 五声）与乐记/与古斋「五正为本」（C1）方向一致，但现代允许偏音更多（28%）——古乐「雅乐禁二变」（G4），现代流行未必要遵古。
- 现代同音反复（78%）与琴乐「取音愈希」（B1/B2）相反——两种审美，工具应按风格分档。
- 大二度是旋律进行的主要音程（10.2%，除同音外第一）——与「级进为骨架」的旋律直觉一致。

## 检查项候选（机器可判）
- **CHK-I1-1 风格音级带**：古风/琴风曲五声占比 ≥ 85%、偏音 ≤15%；流行风可放宽（五声 ≥60%）。按风格标签取不同阈值。
- **CHK-I1-2 同音反复带**：古风曲同音反复占比 ≤ 40%；流行风 ≥40% 可接受。超带按风格提示。
- **CHK-I1-3 音程骨架**：除同音外，大二度 + 小三度占比 ≥ 60%（级进为主）；跳进（≥纯四）过多判「非旋律化」。
