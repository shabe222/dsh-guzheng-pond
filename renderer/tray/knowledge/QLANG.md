# 琴语（QinLang）v2

> **写曲之前先读 `tray/knowledge/CORE.md`**——那一份是蒸馏过的核心手册（3KB），读完就能写。
> 这一份只讲语法。

## 文件骨架（必填）

```
# 标题
@from 起（这一首从哪开始）
@to 落（这一首落到哪）
| ...乐句...
@2000        ← 结尾留白（毫秒）
```

`@from` / `@to` **不写会报错**（“没有声明出口”）。

> **管道自查的编码坑**：PowerShell 5.1 的 `type` 会把无 BOM 的 UTF-8 按 GBK 读，管道给 node 后中文乱码、行尾被吃，报“没有声明出口”的假错。
> 用 `Get-Content -Raw -Encoding UTF8 | ...`，或让 node 直接读文件。

## 音符

`5` 徵 · `5.` 高八度 · `,5` 低八度 · `1 2 3 5 6` 五声
前缀 `^` 重（88）、`^^` 更重（100）；`-` 轻（44）、`--` 更轻（30）

> **低八度的真实音高（2026-10-26 实测）**：
> 不加记号 = D3 E3 F#3 A3 B3（低中音区）；`,1` = **D2（73Hz）**、`,5` = A2（110Hz）——这是古筝真正的低音弦。
> 之前引擎只加载了高处的 10 个采样，所以 `,5` 等于没降；现在修好了。
> 低音要**少而长**：全曲 8-12 个就够，铺底用，别当旋律弹。
后缀 `/1200` 时值毫秒，不写 = 800

## 摇指（长音上快速反复，像手指在弦上来回）

| 写 | 含义 |
|---|---|
| `3Y/2000` | 摇指（默认 80ms 一次），在这个音上摇满 2 秒 |
| `6Y70/2400` | 70ms 一次（更密、更急） |
| `2Y100/1800` | 100ms 一次（更缓、更沉） |

- 只给**长音**用（≥1200ms），短音上摇不起来
- 一首里 2–4 处，别整首都摇
- 和吟猱不叠加：摇是右手反复，吟是左手摆动，二选一

## 按音（4 和 7，不是另录的采样，是左手按出来的）

| 写 | 含义 | 等于 |
|---|---|---|
| `3p100` | 按 3 弦升 100 音分 | **4（清角 G）** |
| `6p200` | 按 6 弦升 200 音分 | **7（变宫 C#）** |
| `5p60` | 微升 60 音分 | 唱腔里的“往上够一下” |

- `p` 后面直接跟音分数；按下去用 0.12 秒，之后停住
- 只能往上按（古筝按弦是升音），要降用注（`z`）
- 用得少而准：一句里一到两处，整首不超过 20% 的音

## 绰注（句首、句尾用，从远处引）

| 写 | 含义 | 方向要求（看**这个音之后**怎么走） |
|---|---|---|
| `c` | 绰（自下而上） | **后一个音比它高**才用 |
| `z` | 注（自上而下） | **后一个音比它低**才用 |

校验器比的是「这个音」和「**它后一个音**」的走向，不是和前一个音。

## 吟猱（分时机 + 幅度）

| 写 | 含义 |
|---|---|
| `~` | 见声吟（弹完停一下再揉）—— 默认 |
| `~d` | **落指吟**：一落弦就揉，像叹气 |
| `~c` | **承声吟**：接上就揉，连着上一句 |
| `~x` | **歇吟**：弹过后才揉，取余声 |
| `~g` | 定吟：微动不露形迹 |
| `~s` / `~l` | 少吟（二转）/ 长吟（八九转） |
| `=` | 猱（缓猱） |
| `=j` | 急猱：紧而疾速，**手急而意缓** |
| `=g` | 定猱：大猱之末 |

## 其他技法

| 写 | 含义 |
|---|---|
| `l` | 历 | `y` 游移 | `q` 起 | `o` 罨 |

## 扫弦

| 写 | 形态 | 何时用 |
|---|---|---|
| `s` | 上扫 | 单用 |
| `f` | 下拂 | 单用 |
| `S` | **大圆（滚拂连用）** | **入调之后** |

可带参：`2S:16:0.34`（每弦 16ms、音量 0.34）
**再加一个数 = 持续秒数**：`5S:16:0.3:3` 就是从 5 开始来回扫 3 秒，一遍比一遍轻
（渐弱的时候用这个，让它自己淡下去）。

## 多音（撮 / 双音 / 三音）

`1+5/1667` —— 一下子拨两根弦（1 和 5），时值写在末尾
`1+3+5/833` —— 三根弦

多音比单音厚；句子重的时候、收尾的时候用它。

## 句子

```
| 3c/700 5/620 3/680 2/640 3~/620 2z/1500 ,900
```

- 一行一句，`,` + 毫秒 = 句后停顿
- 句末必须是 `1` 宫 或 `2` 商
- 故意不落 → 行尾 `?`，**整首只许一处**
- **一句 6–11 个音是常态**（真实琴曲实测中位 6–11），3–4 个音算太短

## 收尾

`@2800` = 弹完后留白，上限 3000（采样余音只有 3.06 秒）

## 校验器会拦下这些

- 哪句没落
- 故意不落超过一处
- 结尾留白 > 3000ms
- 轻起超过 7 成
- 平均句长 < 4 个音
- 绰注方向与走向不符
