# 上下句：悬着的那句，下一句要接住

青花瓷的落点实测：**5→1、3→2、5→1、2→1，段末全归 1**。落音每次不同，归宿只有一个。

## 规矩

1. 上句可以悬（末音落 3/5/6，行尾标 `?`）
2. **悬着的下一句必须接住并落定**（落 1 或 2）
3. 最多连续 3 句不落定，再多就散了
4. **段末归 1**：A / A' / B / 尾，每段最后一句都落 1

## 例

```
| 5/450 6/450 5/900 3/1200 ? ,400     上句：悬
| 3/450 2/450 1/1800 ,400             下句：接住，落 1
```

## 例外

B' 的末句可以落 6（换中心音，代替升半音），紧接着尾句回 1。
