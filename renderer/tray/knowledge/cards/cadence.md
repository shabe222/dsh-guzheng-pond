# 落法：句尾怎么落

同一个落音，有四种说法。选哪种，取决于**这一句到底说完了没有**。

| 落法 | 写法 | 说完没有 |
|---|---|---|
| 稳落 | `1/900` | 说完了 |
| 拖落 | `1/2000` 或 `2/1800` | 说完了，还留着 |
| 滑落 | `2z/1600`、`1c/1800` | 说着说着才落定（z 从上往下滑进来，c 从下往上引） |
| 悬落 | 行尾 `?`，末音落 3/5/6 | 没说完，等下一句 |

## 例（真实写法，可直接照结构）

```
| 3/450 5/450 6/900 5/450 3/1600 ,400           稳→拖
| 5/450 3/450 2/900 1z/1800 ,400                滑落
| 2/450 3/450 5/900 6/900 5/1200 ? ,400         悬落
| 3/450 2/450 1/900 2/450 1~/2200 ,400          拖落 + 迟到的吟
```

## 不要

- 每句都 `1/900`——那不是落，是盖章
- 四种落法平均分配——那是做表格，不是说话。**某一段里同一落法连着两次就够了，第三次换一个**

## 什么时候用哪种

- 这一句是**问句 / 没说完**→ 悬落
- 这一句是**结论 / 收束**→ 稳落或拖落
- 这一句**话里有话**（想说又收回）→ 滑落
