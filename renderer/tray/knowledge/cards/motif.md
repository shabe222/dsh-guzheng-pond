# 动机：一句里先定三个音

一段旋律不是一串好听的音，是**一个念头反复说**。《乐记》：「声成文，谓之音」。

## 做法

1. 挑 **3 个音**（五声里挑，别太花）——这就是这一段的种子
2. 第一句把它们说出来
3. 第二句**同一个骨架，只改尾巴**
4. 第三句**模进**：整体往上或往下挪一格
5. 第四句收

## 例（种子 3-5-6）

```
| 3/450 5/450 6/1600 5/450 3/900 ,400      种子原样
| 3/450 5/450 6/1600 5/450 2/900 ,400      同骨架，尾音换掉
| 5/450 6/450 1/1600 6/450 5/900 ,400      模进（整体挪上去一格）
| 3/450 2/450 1/2000 ,400                  收
```

## 不要

- 四句各写各的：那不是一段旋律，是四段
- 种子每次原样抄（100% 一样）：那是复读，不是变奏。**改尾巴、挪位置都行，音要认得出来**
