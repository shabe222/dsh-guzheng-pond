# 手势：扫弦、多音、迟到的吟、换中心音

## 扫弦（掀起来）

```
5s                 上扫
1S:16:0.34         大圆（滚拂连用），每弦 16ms、音量 0.34
5S:16:0.3:3        来回扫 3 秒、一遍比一遍轻 —— 渐弱收尾用这个
```

一段一次就够。副歌里一次、尾巴一次。

## 摇指（长音的「活」）

```
3Y/2000       默认 80ms 一次
6Y70/2400     更密更急
2Y100/1800    更缓更沉
```

只给 ≥1200ms 的长音用；一首 2–4 处。摇是右手反复，吟是左手摆动，别叠。

## 按音（4 和 7）

古筝的 4、7 不是另录的采样，是**左手按出来的**：

```
3p100      按 3 弦升 100 音分 = 4（清角）
6p200      按 6 弦升 200 音分 = 7（变宫）
5p60       微升，唱腔里「往上够一下」
```

一句一到两处，别多。偏音一出来，味道立刻不一样——但用滥了就变成“跑调”。

## 多音（一下拨几根弦）

```
1+5/1667           两根（撮）
1+3+5/833          三根
```

重的地方、收尾用，全曲 2–3 处。比单音厚。

## 迟到的吟（「候」）

《溪山琴况》：「候宜逗留，则将少息以俟之」——长音要**弹过之后才揉**。

```
3~x/1800           歇吟：弹过再揉
3~w/2000           无意：声将尽才揉
```

## 换中心音（代替升半音）

我们的采样是 D 调五声，升半音做不到。最后一遍副歌改成：

- 末句落 **6（羽）** 并标 `?`
- 尾句再回 **1（宫）**

同一段旋律，冷了半层再回来。
