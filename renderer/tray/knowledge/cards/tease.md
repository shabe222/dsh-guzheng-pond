# 挑逗：压 70%，漏 30%

孔子评《关雎》：「乐而不淫，哀而不伤。」——可以乐，不可以淫；可以哀，不可以伤。
**好曲子不一次把答案给你。**

## 压（七成）

低音区、慢、少、按拍说话。大部分句子应该像“还没开始说”。

## 漏（三成）——三个动作，一段里挑 2–4 个

| 动作 | 怎么写 | 听感 |
|---|---|---|
| 拖 | 一个音拖到 3000 以上 | 该走不走 |
| 高 | 突然一个音跳到高八度（`5.` `1.`） | 抬眼看你一下 |
| 滑 | ≥1600 的长音上带一次绰或注 | 话到嘴边滑过去 |

## 例

```
| 3/450 5/450 6/900 5/450 1./2200 ,400      高：主歌里本来不该有
| 2/450 3/450 5/3500 ,400                   拖：三拍半
| 5c/1800 3/450 2/450 1/900 ,400             滑：从远处引进来
```

## 不要

- 每个音都在撩 → 等于没有撩
- 同一首里两次一样的手势 → 那不是漏，是安排
- 撩完不收 → 结尾必须落 1，让它自己淡
