# 琴味：句与句用「五度链」咬合

> 这是《与古斋琴谱·琴曲收音起句考》的写法：上句末音（收音）决定下句首音（起句），
> 走的是五度链 **宫→徵→商→羽→角→宫**。和流行歌「落 1/2 再随便起」是两套东西。

## 一、硬表

| 上句收 | 下句起 |
|---|---|
| 宫（1） | 徵（5） |
| 徵（5） | 商（2） |
| 商（2） | 羽（6） |
| 羽（6） | 角（3） |
| 角（3） | 宫（1，借正宫） |

**每一对相邻的句子都要按这张表**。这是这一首唯一的骨架，别的地方可以自由。

## 二、例

```
| 3/450 5/450 3/900 2/450 1/1800 ,400       收宫(1) —— 下句必须起徵(5)
| 5/450 6/450 5/900 3/450 2/1800 ,400       起徵(5) → 收商(2)
| 6/450 5/450 6/900 5/450 3/1200 ? ,400     起羽(6) → 收角(3，悬)
| 1/450 2/450 3/900 2/450 1/1600 ,400       起宫(1) → 收宫(1)
```

## 三、句长与气口

- 一句 **6–8 个音**（约 3 秒），句末空隙 **300–500ms**
- 24 句左右，**2 分到 2 分半**

## 四、别的都不管

- 不要套 A/A'/B/B' 结构——这一首靠五度链本身成篇
- 不要每句都落 1；悬着的句子（末音 3/5/6）也要按表接
- 段末落 1（每 8 句一次）
- 技法：长音 `~x`；句首往上 `c`、往下 `z`；结尾一次渐弱扫弦（`1S:16:0.3:3`）

## 五、自查

```
□ 每一对相邻句，是不是按「宫→徵→商→羽→角→宫」接的？
□ 每句 6-8 音、句末 300-500 吗？
□ 最后落 1 了吗？
```
